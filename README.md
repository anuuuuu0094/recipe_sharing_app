# 🍳 Recipe Sharing App

A **modern and responsive recipe-sharing platform** built with **React (Vite)**, **TailwindCSS**, **Firebase**, **Redux**, and **Context API**.  
This application allows users to explore, create, and share recipes in real time with secure authentication and smooth state management.

---

## 🚀 Features

- 🔐 **User Authentication:** Secure user signup and login with Firebase Authentication.  
- 🍲 **Add & Share Recipes:** Users can create, upload, and share their favorite recipes.  
- 🧾 **Real-Time Database:** Recipes and user data are stored and synced instantly using Firebase Firestore.  
- 🎨 **Responsive UI:** Built with TailwindCSS for a sleek and mobile-friendly design.  
- ⚡ **State Management:** Combined **Redux** and **Context API** for scalable, efficient, and maintainable app state.  
- ❤️ **Favorite & Save Recipes:** Users can save recipes for quick access later.  
- 🔍 **Search & Filter:** Easily find recipes by ingredients, category, or name.

## 🧩 Project Overview

The **Recipe Sharing App** enables users to register, browse, create, and share recipes online.  
Using **Firebase**, all data (recipes, likes, and comments) updates in real-time across all devices.  
**Redux** and **Context API** ensure smooth global state management for authentication, recipes, and favorites, providing a seamless experience.

Key modules include:
- User Authentication (Signup/Login)  
- Recipe Feed & Detail Pages  
- Recipe Creation Form  
- Favorites and Search  
- Responsive UI Design

## ⚙️ Setup Instructions

1. **Clone the Repository**
   - `git clone https://github.com/anuuuuu0094/Recipe-Sharing-App.git`
   - `cd Recipe-Sharing-App`

2. **Install Dependencies**
   - `npm install`

3. **Set Up Firebase**
   - Create a new Firebase project in [Firebase Console](https://console.firebase.google.com/).
   - Enable **Authentication** and **Firestore Database**.
   - Add your Firebase configuration details to your project’s config file.

4. **Run the Application**
   - Start the development server:  
     `npm run dev`
   - Open your browser and navigate to:  
     `http://localhost:5173`
